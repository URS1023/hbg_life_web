# AI 网站开发启动任务

用途：用户决定开始开发时，将以下内容交给当前或后续编码 AI。它是待执行任务，不表示项目已实现。

---

请在当前 hbg-life-simulation 仓库中开发一个多用户 AI 视频创作网站。

先读取：

- 仓库及父目录适用的 AGENTS.md。
- docs/web-product-plan.md。
- docs/ai-development-plan.md。
- docs/development-status.md（如已存在）。

目标：用户可从关键词或已有脚本出发，完成规划、角色场景、旁白、分镜提示词、图片、配乐、预览和视频导出。这里由你负责开发项目，不要求在产品中搭建多 Agent 系统。

默认技术方案：Vue 3 + TypeScript + Vite；FastAPI + PostgreSQL；Celery + Redis；私有媒体存储适配层；复用现有 Node.js、Python 和 FFmpeg 制作脚本。正式安装前核对兼容版本并保存锁文件。

执行顺序：

1. 检查当前实现与环境，完成或补齐 M0 的最小数据模型、API 契约、验收标准和开发状态文档。
2. 接着执行 M1，完成登录、私人空间、项目管理与可运行前后端。
3. 接着执行 M2，用显式标记的模拟生成素材打通持久化任务、真实 FFmpeg 合成、任务状态和视频下载。
4. 继续按开发方案的 M3–M8 推进，每一步记录验证结果。优先小样接入真实模型，避免把所有生成调用拖到最后。

工作要求：

- 保留现有制作脚本和规范，通过适配层接入，按需求逐步改造。
- 每次实现完整功能切片，包含页面、接口、数据保存及相关后台逻辑。
- 已完成的功能先检查再修改，不重复重建，不覆盖用户现有改动。
- API 返回稳定类型与错误码；前后端共享明确契约。
- 任务由后台执行，浏览器刷新或关闭不丢状态。
- 用户、项目、资产、任务和下载从第一版就隔离。
- 修改版本、失败重做、取消、去重和额度计量使用服务端持久状态。
- 模型配置未提供时只使用明确的 mock 模式，记录真实集成待完成，不把模拟输出当作真实生成成功。
- 凭据不得写入文档、提示词、日志或版本库；付费调用先明确当前授权范围及预算。
- 所有数据库测试仅用经核实在本机实际运行的数据库；核实主机、端口、库名和服务归属，禁止自动连接局域网或远程库。异常时停止并核查，不自动重试扩大负载。
- 验证应覆盖类型/构建、关键业务、浏览器流程和真实短视频效果，按变更选择必要测试。
- 更新 docs/development-status.md，写清已完成、验证证据、待解决问题和下一项。
- 对已授权的可逆开发操作持续推进，不要每写一个页面都停下询问。外部账号、真实付费、部署和发布按实际授权执行。

每次汇报提供：实际完成的功能、入口或运行方法、检查结果、真实与模拟能力的区别、未解决的具体阻碍。不要仅给计划，也不要在未验收时宣布全部完成。
