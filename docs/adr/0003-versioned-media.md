# ADR-0003：版本化输入和统一渲染清单

状态：Proposed。日期：2026-09-19。

## 背景

当前 `brief_json` 聚合所有阶段，后台直接覆写项目；同一项目复用 preview.mp4。用户编辑、旧任务迟到和并行导出容易互相覆盖，无法解释哪些图片需要重做。

## 决策

内容保存不可变版本，生成绑定 project_revision；素材原始字节不可覆盖，候选与选用分开；依赖图描述过期范围。生产字节放私有存储，数据库保存授权、元数据和引用。

RenderManifest 是预览和正式导出共同输入，固定素材、时序、裁剪、镜头运动、字幕、混音和模板版本；每次导出独立工作目录与 asset。旧任务只产生其输入版本的候选。

## 比较与代价

- 单个 JSON 加 latest 文件实现快，但不能可靠处理并发编辑、历史复现和局部重做。
- 每次复制全部媒体简单却消耗空间；采用不可变资产引用，并保留显式引用表保护 GC。
- 版本和依赖模型增加表数量，需要垃圾回收、快照校验和迁移；换来可重放、可比较及费用可解释。

## 实施与验收

M1 建内容版本，M2 建资产与渲染清单，M5–M6 接入真实素材。VER-02、IMG-02、EXPORT-02、QA-02 必须通过；不可把文件存在当作可用缓存。
