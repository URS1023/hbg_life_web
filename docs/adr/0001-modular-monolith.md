# ADR-0001：模块化单体与独立 Worker

状态：Proposed。日期：2026-09-19。

## 背景

根目录已有 Vue/TypeScript 工作台和 Python/FastAPI 演示 API；制作脚本使用 Node、Shell 和 FFmpeg。用户要求由 AI 完成网站开发，产品核心是可编辑、可恢复的多步骤创作。

## 决策

保留已有前后端框架。业务领域以 Python 模块分离，共用 PostgreSQL，通过 service 边界调用；文本、图片、语音与渲染使用独立执行进程。渲染服务包装根目录制作脚本，部署先用 Compose。

模型承担有限生成节点，流程控制由确定的领域状态与用户确认驱动。AI 开发执行方式不要求把多 Agent 框架嵌入产品。

## 比较与代价

- 全面重写 React/Next 或 Node 后端会增加迁移成本，当前没有证据表明需要。
- 微服务可以独立演进，但会提前引入分布式权限、事务和发布负担，当前规模不支持这一成本。
- 单体需要主动维护模块边界；独立 Worker 镜像和资源隔离仍然必需，否则渲染会占满 API 资源。

## 实施与复审

先完成 M1 工程与权限，M2 任务与真实合成；在多个团队需独立发布或单体资源成为实测瓶颈时重新评估服务拆分。
